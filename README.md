
# Generative AI and Early-Career Labour Demand in Sweden

Master's thesis project – Uppsala University, 2026

## About the Project
This project analyses 3.6 million Swedish job advertisements
from 2021 to 2025 to investigate how occupational exposure
to generative AI relates to early-career labour demand.

## Tools Used
- Python
- pandas and NumPy
- Matplotlib
- SciPy and statsmodels
- Jupyter Notebook

## Research Methods
- Data cleaning and preprocessing
- AI exposure index construction
- Statistical analysis and regression
- Data visualisation
